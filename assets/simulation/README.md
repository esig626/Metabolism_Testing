# Simulation showcase

These images are web-sized presentation copies of existing FluxEMU simulation figures selected for the repository landing page. Resizing and palette reduction were used only to keep the public README lightweight. The full-resolution canonical result files remain in `esig626/fluxemu-prototype`.

Canonical source baseline `711ead67cd739d0e13c16cde34d9d7113b83043d`.

- `biological_flux_distributions.png` comes from `codex/results/mfa_diagnosis/control0_biological_variability/biological_flux_distributions.png`, source blob `c58cc21e43b7e8382eddd4e92eac00a058db7552`. It depicts the controlled synthetic latent flux-state distributions used in the Control 0 biological-variability benchmark.
- `mid_variability_by_metabolite.png` comes from `codex/results/mfa_diagnosis/control0_biological_variability/mid_variability_by_metabolite.png`, source blob `40edf570477fe50b645a993f443086a6b685aff4`. It depicts how the same controlled flux variability propagates into metabolite-level MID variability.

These are synthetic simulation outputs, not raw biological observations and not evidence of biological validation.
