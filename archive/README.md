# Archive

This directory contains historical migration material retained for provenance rather than presented as the current scientific state of the project.

`migrations/data/` preserves the tracked migration backup directory, including historical `papers` snapshots and the known-repairs table. `migrations/migrations.zip` preserves the uploaded migration archive exactly as received.

The migration report itself remains under `audit/migration_report.md`, matching the path used by the existing migration script. Historical corpus snapshots in this archive must not be treated as the canonical current corpus without a separate recovery check.
