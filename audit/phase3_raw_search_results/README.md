# Phase 3 raw search results

The directory structure follows `audit/phase3_search_log.md`.

- `A/` contains direct MID-level inference search captures.
- `B/` contains testing-without-identification search captures.
- `C/` contains network-coupled parallel-observation search captures.
- `D/` contains hierarchical experimental-pipeline search captures.
- `E/` contains induced-family geometry search captures.
- `citation_checks/` contains the tracked anchor and forward-citation captures.
- `verification/` contains primary-source verification material and explicitly preserved empty or failed retrieval artifacts.

Existing raw files were assigned using the filenames and locations recorded in the Phase 3 search log. Their Git blobs were not altered.
