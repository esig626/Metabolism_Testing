# Synthesis

This directory contains cross-source synthesis rather than raw evidence or individual methodological analyses.

- `method_taxonomy.md` organises the methodological landscape.
- `candidate_gaps.md` records candidate methodological gaps for testing rather than assuming them to be novel.
- `old_vs_new_matrix.md` compares earlier and revised formulations.
- `rejected_novelty_claims.md` preserves claims that were weakened or rejected by the literature audit.

These files remain subordinate to the primary-source evidence and audit trail. Their relocation does not strengthen any novelty or absence claim.
