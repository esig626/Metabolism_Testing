# Scripts

This directory is for reproducible utilities that support searching,
deduplication, metadata checking, evidence validation, analysis, and report
generation.

Each script should document its purpose, inputs, outputs, dependencies,
version assumptions, and invocation. Prefer deterministic behaviour and
machine-readable logs. Scripts must not silently overwrite manually curated
evidence or source files; use explicit output paths, preserve provenance, and
require review before merging generated changes.

Phase 0 contains no literature-search scripts and does not authorise searches
or downloads.
